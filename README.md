# Atelier Façade — платформа фасадного декора

Каталог, 3D-конструктор фасада, автоматический расчёт материалов и стоимости, сметы, сохранённые
проекты и заявки. Интеграционный слой подготовлен под существующую CRM компании.

> **DEMO.** Изделия, цены, нормы расхода, портфолио и контакты — демонстрационные (артикулы `DEMO-…`).
> CRM не подключена: заявки **не уходят** менеджеру, проекты хранятся **только в браузере**.
> Бренд «Atelier Façade» — временное название, замените в `src/lib/site.ts` и словарях.

**Демо-сайт:** https://abylakhan.github.io/facade-decor-platform/

## Тёмный редизайн и видео-трансформация (последняя итерация)

- **Главный экран** — прокрутка управляет секвенцией из 165 кадров: синий чертёж двухэтажного
  дома → каркас на местности → тот же дом с материалами и черепичной крышей → лёгкий наезд камеры
  и финальный заголовок. Источник — два ролика Pixabay одного автора с одной камерой и одним домом;
  этап «чертёж» извлечён из самих кадров каркаса, поэтому геометрия не «прыгает». Кадры рисуются на
  `<canvas>` (без джиттера перемотки видео в Safari/iOS), загружаются постепенно, под холстом —
  постер; мобильный набор 800 px; reduced motion — статичный финальный кадр.
- **Тёмная палитра** — графит, тёплый слоновой кости текст, бронзовые акценты; печать сметы
  остаётся светлой (переопределение токенов в `@media print`).
- **Скролл-эффекты по всей главной** — манифест «загорается» по словам, горизонтальная закреплённая
  лента изделий, линия процесса заполняется прокруткой, «до/после» раскрывается прокруткой,
  CTA с дрейфом сетки; карточки каталога наклоняются за курсором; итоговые суммы плавно
  перетекают (точное значение сразу доступно скринридеру).
- **Псевдо-3D поворот** в конце: дом вырезан по контуру, фон (чистый кадр сцены) уходит в параллакс,
  а дом поворачивается в перспективе (полосовая деформация на canvas) и реагирует на курсор.
  Это 2.5D-эффект, а не настоящая 3D-модель.

## Редизайн (визуальный слой)

Бизнес-логика, расчёты, маршруты и контракты не менялись — 58 тестов проходят до и после
(чек-лист сохранённой функциональности: [docs/REDESIGN_CHECKLIST.md](docs/REDESIGN_CHECKLIST.md)).

- **Главный экран** — архитектурный чертёж демо-фасада, построенный из той же модели проекта, что
  использует конструктор: линии прорисовываются при загрузке и прокрутке, затем декор получает тон
  и нумерованные выноски с артикулами каталога. Отметки уровней и размерная цепочка — из геометрии.
- **Студийные 3D-визуализации изделий** (27 шт., `public/renders`) — рендеры собственных
  параметрических моделей изделий; в каталоге при наведении проявляется технический чертёж.
- **3D-конструктор** — PBR-материалы (Poly Haven, CC0), HDRI-освещение, мягкие тени, AO и
  сглаживание на мощных устройствах, плавная смена цветов, подсветка редактируемого декора,
  анимация появления элементов.
- **Motion-система** — появление секций, раскрытие заголовков по словам, маски изображений,
  переход страниц, подчёркивание активного пункта меню, переключатель языка со скользящим
  индикатором; всё отключается при `prefers-reduced-motion`.
- **Переключение языка** сохраняет позицию прокрутки, query-параметры (фильтры, проект),
  состояние быстрого калькулятора, вкладку и ракурс конструктора, черновик формы.
- Источники и лицензии: [public/assets/LICENSES.md](public/assets/LICENSES.md).

Ограничения (честно): внешнюю фотореалистичную модель дома подключить не удалось — легальные
качественные модели требуют аккаунта; одна скачанная (сгенерированная ИИ) была отклонена, загрузка
второй блокировалась сетью. Дом в 3D-конструкторе остаётся параметрическим, потому что на нём
работает связка «декор → расчёт → смета». Английский язык пока не добавлен (архитектура готова).
При смене языка 3D-сцена конструктора перезагружается (проект и ракурс сохраняются).

## 1. Запуск

Требуется Node.js 24 LTS.

```bash
npm ci
npm run dev        # http://localhost:3000  (при проблемах с Turbopack: npx next dev --webpack)
npm test           # 58 unit-тестов (vitest)
npm run typecheck
npm run build      # статический экспорт в ./out
```

Переменные окружения — `.env.example`. Деплой на GitHub Pages выполняется автоматически
при push в `main` (`.github/workflows/pages.yml`: typecheck → тесты → сборка → публикация).

## 2. Стек

Next.js 16 (App Router, static export) · React 19 · TypeScript (strict) · Tailwind CSS 4 ·
three.js + React Three Fiber + drei · zod 4 · vitest. Анимации — CSS + requestAnimationFrame
(без GSAP: прокрутка вступления реализована напрямую через прогресс скролла).

## 3. Структура модулей

```
src/

    types.ts              изделия, единицы, цены, правила, геометрия, проекты, сметы
    schemas.ts            zod-схемы проекта и заявки

    calc/
      geometry.ts         площади, проёмы, углы, валидация, система координат и точки привязки
      layout.ts           позиции пилястр, колонн, кронштейнов (общие для 2D и 3D)
      rules.ts            правила количества по типам размещения
      estimate.ts         агрегирование, цены, работы, доставка, скидки, итог
      math.ts             округление, раскрой (first-fit decreasing)

  components/
    three/                HouseModel (параметрический дом и декор), FacadeScene, HeroScene, превью
    drawings/             SVG-фасад (схема, PDF, fallback без WebGL), технические чертежи изделий
```

Одна модель проекта (`Project → Variant`) используется 3D-сценой, спецификацией, калькулятором,
сметой и заявкой. Любое изменение размеров/декора пересчитывает смету мгновенно (`useProjectState`).

## 5. Формулы

Подробно — [docs/CALCULATIONS.md](docs/CALCULATIONS.md). Кратко:
площадь стены = длина × высота; полезная = площадь − проёмы; профили — ⌈(линии + углы) × (1+запас) /
полезная длина⌉; обрамления — план раскроя по сторонам проёма по схеме 4/3/верх; штучные —
по геометрии + технологический запас; итог = материалы + работы + доставка + доп. расходы − скидки.

## 6. Демонстрационные данные

- `src/data/demo-catalog.ts` — 27 изделий в 17 категориях (артикулы `DEMO-*`, `source: "demo"`),
  профили сечений, нормы клея/герметика, комплекты, угловые элементы. 2 изделия без цены («по запросу»).
- `src/data/demo-prices.ts` — прайс `DEMO-2026.10`: цены, расценки монтажа, доставка, скидка 5 % от 3 млн ₸,
  «под ключ» недоступно.
- `src/data/presets.ts` — 4 концепт-проекта (не реализованные объекты).
- `src/data/content.ts` — статьи, FAQ, услуги (справочные тексты, требуют проверки компанией).

## 7. Временные и тестовые механизмы

| Механизм | Где | Ограничение |
|---|---|---|
| DEMO-каталог и прайс | `DemoCatalogProvider`, `DemoPricingProvider` | вымышленные данные |
| Хранение проектов | `BrowserProjectProvider` (localStorage) | только этот браузер; есть экспорт/импорт JSON |
| Заявки | `DemoQuoteProvider` (локальный outbox) | менеджер **не получает** заявку — UI говорит об этом |
| Файлы в заявке | проверка типа/размера/количества | файлы никуда не загружаются |
| Антиспам | honeypot + минимальное время заполнения + idempotency key | клиентские; серверные — в `src/server/` |
| PDF | печать браузера («Сохранить как PDF») | реальный PDF с кириллицей, без серверной генерации |
| WhatsApp | `wa.me` с готовым текстом | номер компании не задан → откроется выбор контакта |
| Индексация | `robots` закрыт в DEMO | открывается при `DATA_SOURCE=crm` |

  площадь, сопутствующие материалы, минимальная партия, цена «по запросу», монтаж/доставка/скидка,
  ручные правки, смена версии цен, отсутствие размеров, сохранение/загрузка/порча хранилища,
  заявки (спам, дубли, rate limit, серверный пересчёт, отказ CRM), поиск, полнота перевода kk.
- `npm run typecheck` и `npm run build` — без ошибок; статически собраны все страницы ru/kk.
- Вручную в браузере: вступление (все фазы), каталог, карточка (kk), конструктор (3D + спецификация),

## 10. Что работает и что требует внешних ресурсов

**Работает сейчас:** каталог (поиск, фильтры, сортировка, избранное, сравнение, быстрый просмотр,
чертежи и 3D-превью из данных изделия), 3D-конструктор (вращение/масштаб/камеры, день/вечер, цвета,
материалы стен, все типы декора с привязкой к геометрии, варианты и их сравнение), калькулятор
(быстрый и профессиональный, объяснение каждой позиции, история, ручные правки, доп. расходы),
сохранение проектов в браузере, смета с печатью/PDF и фиксацией версии цен, список закупки,
форма заявки с валидацией (DEMO), WhatsApp-ссылка, ru/kk, SEO-метаданные, адаптивность,
reduced motion, fallback без WebGL.

**Требует интеграции или ресурсов:**
- CRM: каталог, цены, наличие, медиа, приём заявок и статусы — нужен доступ к API.
- Реальные фото, чертежи и GLB-модели изделий (поддержка GLTF в коде есть — `model3d.kind = "gltf"`).
- Фотореалистичное вступление: сейчас реальная 3D-сцена в реальном времени (чертёж → объём →
  материалы → облёт). Для фотореалистичного уровня нужен заранее отрендеренный ролик/секвенция.
- Серверный деплой (Node.js) для приёма заявок, загрузки файлов и серверного хранения проектов.
- Реальные контакты, номер WhatsApp, юридический текст политики, название и фирменный стиль.
- Распознавание фасада по фото — не реализовано (используется ручной ввод размеров).
