# Формулы и правила калькулятора

Весь расчёт находится в `src/domain/calc/` (чистый TypeScript, без React) и покрыт тестами
`src/domain/calc/*.test.ts`. 3D-конструктор, быстрый и профессиональный калькулятор, смета и
серверный обработчик заявок вызывают одну функцию `buildEstimate(variant, catalog, priceList)`.

Единицы: геометрия — метры, размеры изделий — миллиметры, деньги — целые тенге (KZT).

## 1. Геометрия (`geometry.ts`)

| Величина | Формула |
|---|---|
| Высота стены до карниза `H` | `цоколь + этажи × высота этажа` |
| Длина стены | фасад/задняя = `длина дома`, боковые = `ширина дома` |
| Площадь стены | `длина × H` |
| Полезная площадь стены | `площадь стены − Σ(ширина × высота проёмов)` |
| Общая полезная площадь | сумма полезных площадей выбранных сторон (зон) |
| Внешние углы | пары соседних выбранных сторон по кольцу фасад → правая → задняя → левая |

Проверки геометрии: обязательные размеры (> 0), проём внутри стены и этажа, проёмы не пересекаются.
При отсутствии размеров геометрические позиции **не считаются** и выводится ошибка — скрытые значения не подставляются.

## 2. Погонные профили (карниз, пояс, цоколь, профиль по длине)

```
длина линий      = Σ длин выбранных сторон × число линий
                   (карниз и цоколь — 1 линия, пояс — этажи − 1)
запас на углы    = внешние углы × 2 × вынос профиля   (рез на ус)
                   = 0, если выбраны готовые угловые элементы (тогда + N угловых элементов)
требуемая длина  = (длина линий + запас на углы) × (1 + запас на подрезку)
количество       = ⌈ требуемая длина / ПОЛЕЗНАЯ длина изделия ⌉
```

Полезная длина — длина, реально доступная для монтажа (номинал минус технологические торцы),
например 1,96 м у изделия 2,0 м.

## 3. Обрамления окон и дверей

Схемы: **4 стороны**, **3 стороны** (без низа), **только верх** (сандрик).
`f` — ширина лицевой части профиля.

| Схема | Отрезки на один проём |
|---|---|
| 4 | верх `w+2f`, низ `w+2f`, 2 × бок `h+2f` |
| 3 | верх `w+2f`, 2 × бок `h+f` |
| top | верх `w+2f` |

К каждому отрезку добавляется припуск на рез с двух концов. Отрезки длиннее полезной длины
изделия делятся на равные части со стыками. Количество изделий определяется **планом раскроя**
(first-fit decreasing): обрезки одного изделия используются для других отрезков.
Дополнительный запас (`wasteOverride`, профрежим) умножает число изделий.

## 4. Штучные изделия

| Размещение | Количество |
|---|---|
| Замковые камни | число проёмов выбранного типа на выбранных сторонах, **кроме** проёмов, где камень уже входит в комплект обрамления |
| Угловые русты | `⌈(H − цоколь) / модуль руста⌉ × число углов` |
| Пилястры / полуколонны | `стороны × шт на сторону × ⌈высота / макс. высота изделия⌉` (стык → предупреждение) |
| Колонны | заданное количество; проверка допустимой высоты (иначе позиция **не добавляется**) и пропорции высота/диаметр (предупреждение) |
| Кронштейны | `Σ (⌊длина стороны / шаг⌋ + 1)` |
| Балюстрада | `⌈длина / длина секции⌉` |
| Ручные позиции | указанное количество |

Технологический запас для штучных: `⌈количество × (1 + запас)⌉`.

## 5. Площадные материалы

`упаковки = ⌈полезная площадь × расход на м² × (1 + запас) / объём упаковки⌉`.

## 6. Сопутствующие материалы

Нормы клея/герметика задаются в карточке изделия (на метр или на штуку). Потребность суммируется
по всем позициям и **округляется один раз** в конце — без завышения от округления каждой позиции.

## 7. Агрегирование и защита от двойного счёта

- одна строка сметы на изделие (сумма по всем размещениям);
- комплектные элементы (`kitIncludes`) не считаются повторно;
- применяется минимальная партия (с пометкой);
- ручная правка количества (профрежим) заменяет расчётное значение, расчётное остаётся видно.

## 8. Стоимость

```
материалы  = Σ количество × действующая цена       (позиции «по запросу» не входят в итог)
работы     = Σ установленный объём × расценка      (только «материалы и монтаж» / «под ключ»)
доставка   = самовывоз 0 | город — фикс. | регион — база + ставка × км (без км → предупреждение)
скидка     = % от материалов по правилу прайса
итог       = материалы + работы + доставка + доп. расходы − скидка
```

Работы считаются от установленного объёма (без запаса на подрезку).
Если есть позиции без цены или неизвестна доставка, итог подписан как «без позиций по запросу».

## 9. Версии цен

Каждый расчёт хранит `priceListVersion` и `calculatedAt`. Кнопка «Зафиксировать смету» сохраняет
снимок расчёта в варианте проекта. Если текущая версия прайса отличается, смета показывает
предупреждение и даёт выбрать: зафиксированный расчёт или пересчёт по текущим ценам.

## 10. Сообщения

Каждое сообщение имеет код и уровень:
`error` — позиция **не включена** (нет сторон, нет проёмов, высота вне диапазона, нет размеров…),
`warn` — включена, но требует проверки, `info` — допущение.
Тексты на двух языках — `src/i18n/*.ts → calc.msg`.
