# Интеграция с CRM

> Статус: **не подключено.** Доступа к CRM нет, поэтому её API, сущности и поля неизвестны.
> Код не выдумывает их: `HttpCrmAdapter` намеренно выбрасывает `CrmNotConfiguredError`.
> Синхронизация с CRM **не работает**, пока адаптер не реализован и не прошёл интеграционные тесты.

## Архитектура

```
UI (React)  ──>  CatalogProvider / PricingProvider      (server: build-time или runtime)
            ──>  ProjectProvider                         (сохранённые проекты)
            ──>  QuoteProvider                           (заявки)
                        │
          DATA_SOURCE=demo                     DATA_SOURCE=crm
          ├─ DemoCatalogProvider               ├─ CrmCatalogProvider ─┐
          ├─ DemoPricingProvider               ├─ CrmPricingProvider ─┼─> CRMAdapter (HttpCrmAdapter)
          ├─ BrowserProjectProvider (local)    └─ server/leads.ts ────┘
          └─ DemoQuoteProvider (local outbox)
```

- Режим выбирается **серверной конфигурацией** (`DATA_SOURCE`), а не кнопкой в интерфейсе.
- Источник истины для каталога, цен и заявок — CRM. Сайт не дублирует её функции и не даёт
  посетителям редактировать каталог; отдельной админ-панели нет.
- Интерфейсы: `src/integration/types.ts`. Демо-реализации: `src/integration/demo/`.
  Заготовка CRM: `src/integration/crm/adapter.ts`. Выбор провайдеров: `src/integration/server.ts`.

## Операции `CRMAdapter`

| Метод | Назначение | Обязателен |
|---|---|---|
| `fetchCategories()` | категории каталога | да |
| `fetchProducts()` / `fetchProduct(id)` | изделия и их параметры | да |
| `fetchPriceList()` | актуальные цены, версия прайса, расценки работ, доставка, скидки | да |
| `fetchAvailability?(ids)` | наличие / остатки | если CRM поддерживает |
| `fetchMedia?(id)` | фото, чертежи, 3D-модели (GLB/GLTF) | если хранятся в CRM |
| `createLead(input)` | создание заявки; получает **серверно пересчитанную** смету | да |
| `sendSpecification?(ref, estimate)` | передача спецификации | если поддерживается |
| `sendConfiguration?(ref, project)` | передача 3D-конфигурации | если поддерживается |
| `getLeadStatus?(ref)` | статус обработки заявки | если поддерживается |

## Что нужно от компании для подключения

1. Документация API CRM (REST/GraphQL/иное), базовый URL, тестовый стенд.
2. Способ аутентификации и **серверный** ключ/токен (хранится только в переменных окружения сервера).
3. Модель данных изделия: идентификаторы, артикулы, категории, единицы продажи, размеры, материалы.
4. Технологические параметры для расчёта (если есть в CRM): полезная длина, запас на подрезку,
   припуски, модуль рустов, допустимые высоты колонн, нормы клея/герметика, комплектность.
   Если их нет в CRM — согласовать, где они ведутся.
5. Прайс: цены, валюта, правило версионирования, расценки работ, доставка, скидки.
6. Наличие / остатки и политика обновления (как часто, кэширование, вебхуки?).
7. Медиа: где лежат фото, чертежи, 3D-модели; права на использование.
8. Заявки: обязательные поля, куда прикладывать файлы и PDF, какие статусы возвращаются.
9. Лимиты запросов, требования к безопасности, ПДн (закон РК «О персональных данных и их защите»).
10. Политика обновления каталога на сайте (ISR/пересборка/вебхук) и время устаревания цен.

## План подключения

1. Реализовать методы `HttpCrmAdapter` и мапперы «сущность CRM → `Product`/`PriceList`».
2. Прогнать контрактные тесты (скопировать проверки из `src/integration/integration.test.ts`
   для демо-провайдера на CRM-провайдер на тестовом стенде).
3. Развернуть сайт на сервере с Node.js (Vercel / свой сервер), а не только как статический
   экспорт: нужен API-маршрут для заявок. Готовый обработчик — `src/server/leads.ts`
   (zod-валидация, rate limit, idempotency, серверный пересчёт сметы, отсутствие логирования ПДн).
4. Заменить `BrowserProjectProvider` серверным `ProjectProvider`, если проекты должны храниться
   на сервере/в CRM (сейчас — только в браузере, о чём явно сказано в интерфейсе).
5. Установить `DATA_SOURCE=crm`, проверить заявку от начала до конца на тестовом стенде.
6. Открыть индексацию (`robots.ts` открывает её автоматически при `DATA_SOURCE=crm`).
